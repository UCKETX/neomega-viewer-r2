操作帮助

预览与时间

体素渲染器
用纯色方块简化模型，省去贴图和光影，资源占用最低。适合快速浏览大范围地形。
基础渲染器
显示完整方块模型和贴图，方便检查建筑的形状与用材。
光影渲染器
加入阴影、远景雾和水面反射，适合观察光照或取景。
隐藏 HUD
收起工具栏和读数，让出观察空间。右上角只留一只划掉的眼睛，点它即可恢复。
静止时累积
停下相机后持续采样，让画面逐渐清晰。开启时会暂停时间流逝。
时间流逝
让太阳随时间移动，观察昼夜光照。拖动右侧滑条可直接选择时刻。

地图与画面

全屏地图
从上方查看周围地形。点选方块后可跳转到该处，再点地图图标或按 Esc 返回。
导出当前画面
用当前预览渲染器重绘视图，采样完成后自动保存 PNG。适合保留当前画面风格。
拍照
用累积渲染器逐步细化照片。满意时再按一次相机保存 PNG，按 Esc 可放弃。
设置
按相机、光照、画面、输出和参数组分页。面板贴在屏幕一侧（竖屏时在底部），打开时收起底栏，可以一边拖动视角一边调整。

坐标与存档

导出离线 HTML
保存当前维度、材质、镜头与光照设置。离线打开后会从导出时的视角继续浏览。
跳转到坐标
编辑底部的 X、Y、Z 后点箭头或按回车，直接飞到指定位置。
场景信息
点击场景名称可查看存档路径和加载信息。多维度存档还可在这里切换维度。
连接数据源
填写 R2Link 地址，从游戏机器人、服务器插件或存档服务加载世界。
打开存档
选择服务端上的世界目录或结构文件，在查看器中打开。
关闭存档
离开当前存档或断开外部数据源，回到内置的莫比乌斯环场景。
操作帮助
打开这份图标说明。点右上角的关闭按钮或按 Esc 返回。

移动与地图缩放

水平移动
触屏方向键按相机朝向前进、后退或左右平移。键盘使用 WASD。
升降
触屏升降键沿高度方向移动。键盘用空格上升、Shift 下降。
地图缩放
拖动地图底部的滑条，从局部地形缩放到大范围概览。

查看器沿用了 neOmega Viewer 的存档浏览方式，使用 neOmega R2 的射线渲染器绘制大范围地形与光影。

本机和 HTTPS 页面优先使用 WebGPU，普通局域网 HTTP 页面使用 WebGL。右上角的标签显示当前后端。

本项目未直接使用以下项目的代码，但许多关键数据来自它们： Amulet、 GeyserMC 和 MC-Assets。 本项目已在 amuletmc.com 购买 Amulet 授权（2026-11-07，订单号 KBPp706mBN）。

场景信息

1 个 r2region 横向覆盖 8×8 个区块（chunk）。每个区块按高度分层，每 16 层是一个 16×16×16 方块的子区块（subchunk）。

连接数据源

由游戏机器人、服务器插件或存档服务提供。连接成功后关闭当前存档。
